# References

Maintain a complete, consistent list of sources used in the report. Cite sources in the text and make sure every in-text citation has a matching entry here and vice versa. Follow the citation style required by the institute or supervisor; no style is assumed in this template.

Keep source records in `reference-register.md`. Include author or organization, title, publication date, publisher or venue, DOI or stable URL, and access date for web resources when required.
