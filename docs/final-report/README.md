# Final Report

This folder contains the report draft and its supporting front matter, chapter drafts, appendices, and reference list. `report-requirements.md` consolidates the sections and checks visible in the professor-provided templates; confirm any unclear items and formatting rules with the supervisor or institute guide.

## Recommended order

1. Cover page(s), using the language and layout required by the institute.
2. Declaration and team contribution information.
3. English abstract and acknowledgment.
4. Table of contents and list of figures (and tables if required).
5. Chapters 1–6 in order.
6. Appendices.
7. References.
8. Arabic summary if required by the institute.

Start each chapter on a new page in the final document. Generate the contents and figure lists from final headings and captions rather than copying old page numbers. Number chapters, sections, figures, and tables consistently. Confirm the font, margins, page numbering, citation style, languages, and required export format with the supervisor; none are specified here.

These Markdown files are drafting outlines, not a completed report. Replace placeholders with project-specific, supervisor-approved content. Do not submit empty templates or copied sample page numbers.
