# Report Front Matter

Prepare the pages that appear before Chapter 1 here. Use the institute's official template if one is provided. Personal student records should be added only to the access-controlled submission copy when required; do not store private phone numbers or personal email addresses in this repository.

Expected items may include a cover page, declaration, student contribution table, English abstract, acknowledgment, table of contents, list of figures, and an Arabic summary. Confirm which languages and pages are required with the supervisor.
