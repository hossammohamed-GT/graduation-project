# Editable System Diagrams

Store editable source files for analysis and design diagrams here. Use clear names such as `system-context`, `data-flow-level-0`, `sequence-primary-scenario`, and `use-case-overview`.

Depending on the approved project, diagrams may include a functional decomposition, workflow or flowchart, system-context diagram, data-flow diagrams, sequence diagram, use-case diagram, architecture diagram, and hardware or wiring diagrams.

For every diagram:

1. State its purpose and scope.
2. Use consistent terminology with the requirements and report.
3. Add a version/date or change note when it is revised.
4. Export a readable copy to `assets/diagrams/` for reports or presentations.
5. Do not include a diagram that does not apply to the project merely to fill a template.
