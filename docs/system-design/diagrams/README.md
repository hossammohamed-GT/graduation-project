# Editable Software-System Diagrams

Store editable source files for analysis and design diagrams here. Use clear names such as `system-context`, `learner-workflow`, `data-flow-assessment`, `sequence-tutor-session`, and `use-case-overview`.

Depending on the approved MVP, diagrams may include functional decomposition, learner workflow, system context, data flow, sequence, use-case, and software-architecture diagrams. The project has no planned robot, Smart Mirror, hardware, or wiring diagrams.

For every diagram:

1. State its purpose and scope.
2. Use terminology consistent with the requirements and report.
3. Add a version/date or change note when it is revised.
4. Export a readable copy to `assets/diagrams/` for reports or presentations.
5. Do not include a diagram that does not apply to the approved MVP merely to fill a template.
