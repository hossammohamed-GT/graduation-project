# System Design

This folder explains how the approved requirements are realized by the project's components and interfaces.

- `architecture.md` — system boundary, components, responsibilities, interfaces, data flow, and design decisions.
- `diagrams/` — editable system-analysis and design diagrams, plus a short description of each.

Keep the design consistent with `docs/requirements/`. Include hardware or deployment details only when they are part of the approved project scope. Put report-ready exported images in `assets/diagrams/` and retain editable sources here.
