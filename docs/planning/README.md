# Project Planning

Use this folder to establish and maintain the approved project plan before and during implementation.

## Store here

- `project-charter.md` — project problem, goals, scope, stakeholders, constraints, and success measures.
- `meeting-notes/` — dated decisions and action items from team or supervisor meetings.

## Working rules

Record decisions with a date and an owner. Distinguish confirmed decisions from open questions. Update the charter when the supervisor approves a scope change, and reflect the change in requirements and task assignments.
