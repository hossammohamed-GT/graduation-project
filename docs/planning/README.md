# Project Planning

Use this folder to establish and maintain the approved project direction before and during implementation.

## Store here

- `project-charter.md` — project problem, goals, stakeholders, constraints, success measures, and current proposed MVP scope.
- `project-overview.md` — broad child-development vision, the software-only MVP boundary, long-term ideas, and decisions to confirm.
- `meeting-notes/` — dated decisions and action items from team or supervisor meetings.

## Working rules

Record decisions with a date and an owner. Distinguish confirmed decisions from open questions. The current plan excludes hardware and focuses the first delivery on a responsive English-learning software subsystem; update both planning documents if the supervisor approves a change.
