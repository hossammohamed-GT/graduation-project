# Documentation

This directory contains the written project record: planning, research, requirements, system design, implementation notes, testing documentation, the final report, and presentation material. Keep technical source code in `src/` and physical-design files in `hardware/`.

## Subdirectories

- `planning/` — project charter, scope, objectives, and meeting records.
- `research/` — literature review and notes about related work.
- `requirements/` — functional and non-functional requirements and use cases.
- `system-design/` — architecture decisions and editable analysis/design diagrams.
- `implementation/` — human-readable implementation notes and setup explanations.
- `testing/` — test plans, manual results, and validation evidence.
- `final-report/` — report front matter, six chapter drafts, appendices, and references.
- `presentation/` — slide outline, demo plan, and presentation notes.

Use the README in each subdirectory for detailed instructions. Replace every `[TODO]` placeholder before submission.
