# Automated Tests

Store executable tests here. Keep test code aligned with the implemented project stack and document how to run it once the tooling is selected.

- `unit/` — tests of small isolated functions or components.
- `integration/` — tests of interactions between components or services.
- `system/` — end-to-end or system-level verification.

Test data should be synthetic or approved, small, and non-sensitive. Record manual test procedures and results in `docs/testing/`.
