## Assignment guidelines

- Keep the task IDs stable so they can be referenced in meetings and progress updates.
- Each task should have one clearly accountable primary owner; add contributors in the same cell if needed.
- Agree on dependencies and deadlines with the supervisor; no dates are assumed in this template.
- A task is **Complete** only when its deliverables are saved in the listed location and reviewed by the team.
